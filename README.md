# All Projects

Master catalog for the public and private projects owned by **ArkansasIo**.

## Purpose

This repository is the central index for the project portfolio. Original repositories remain authoritative and are **not modified or merged destructively**.

## Organization

Projects are cataloged by repository and grouped by broad technical area:

- AI and research
- Games and MMORPGs
- Emulators and retro computing
- Game engines and tools
- Web servers and applications
- Hardware and robotics
- Operating systems and systems software
- Utilities and experiments

## Repository policy

Each source repository keeps its own Git history, issues, branches, releases, and licenses. This master repository provides the portfolio-level index and project metadata.

Large projects should be referenced or attached as Git submodules/snapshots rather than blindly duplicating their complete Git histories.
